# GIMSUGA website prototypes

Clickable demos of three possible directions for a chapter website, shown to members before the
chapter executive decides. **Prototype — not a real site.**

- **A — Lean:** chapter information, officers, events, the chapter's work, how to join. No member data.
- **B — Members area:** A plus member login, profiles, a member directory and a business directory.
- **C — Community portal:** B plus event RSVPs, member-posted news and event galleries.

## Rules for everything in this repository

This repository is public, and git history is permanent. Everything here must be safe to publish forever.

- **Fictional people only.** Every name, photo, business and profile is invented and labelled as fictional.
  No real member, officer or photograph of a real person, ever.
- **No real data is collected.** Anything that looks like saving is held in your browser only, and every
  page says so. There are no accounts; "View as a member" is a button, never a password field.
- **Every page** carries the prototype banner, the demo bar (direction A/B/C and viewpoint Visitor /
  Member / Chapter officer, settable by link, e.g. `?dir=B&as=member`) and `noindex`.
- **No tracking, cookies or embeds.** The questionnaire is linked, not embedded.
- **Photos** are props or licensed stock, with the licence recorded.
- **Nothing from the planning workspace comes in:** no research notes, questionnaire responses, phone-call
  notes, contact details, secrets, `.env` files or machine paths.
